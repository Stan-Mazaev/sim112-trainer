# Демо-стенд для жюри

Статическая версия фронтенда — работает без бэкенда.

## Что работает

- Все 24 сценария из билетов
- Приём звонка, opening_line заявителя
- Реплики заявителя по 8 предзаписанным сценариям (реальные ответы из прогонов)
- Заполнение карточки, активация служб
- Метрики, нарушения, оценка
- Скачивание PDF-примера
- Панель инструктора: список сессий, поток событий

## Что отключено

- Голосовой ввод (STT)
- Голос заявителя (TTS)
- Реальный WebSocket

Полная версия с голосом — в основном репозитории.
